# Portfolio (Vite + React + Tailwind)

Quick scaffold for a portfolio site built with Vite, React and Tailwind CSS. Designed to deploy to Netlify.

Setup

```bash
cd portfolio
npm install
npm run dev
```

Build

```bash
npm run build
```

Deploy to Netlify

- Push this repo to GitHub.
- In Netlify, choose "New site from Git" and connect the repo.
- Set the build command to `npm run build` and the publish directory to `dist`.
- (Optional) Netlify will detect and use `netlify.toml` for settings.
